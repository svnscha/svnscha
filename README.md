# Hi, I'm Sven

**Win32, kernel enthusiast and language-crafting aficionado.**

I'm a Principal Systems Software Engineer at [Citrix](https://citrix.com), [Cloud Software Group](https://cloud.com), where I work on Citrix Experience Insights (formerly uberAgent), and the founder of [Liasoft](https://liasoft.de). Low-level programming is my foundation: Win32, Windows internals, driver development and language crafting, with more than 15 years of C++.

## What I build in the open

- **[mcp-windbg](https://github.com/svnscha/mcp-windbg)**: an MCP server that lets AI assistants drive WinDbg and CDB, from crash-dump triage to live user-mode and kernel debugging.
- **[dap-dbgeng](https://github.com/svnscha/dap-dbgeng)**: native Windows debugging for Visual Studio Code, built on the WinDbg engine ([extension](https://marketplace.visualstudio.com/items?itemName=svnscha.vscode-dap-dbgeng)).
- **[covdbg](https://covdbg.com)**: C++ code coverage on Windows through dynamic binary instrumentation, with no recompilation. Its tools live in the [Liasoft organization](https://github.com/liasoft).
- **[antispy SDK](https://antispy.xyz)**: Liasoft's compile-time C++ obfuscation library.
